# SmartEvent brand assets

## Identity

- Primary: terracotta `#c74b31`.
- Warm accent: apricot `#f4aa83`.
- Light background: ivory `#fff3e9`.
- Dark background: ink `#182230`.
- Symbol: an admission ticket with a six-ray spark. The ticket represents access to an experience; the spark represents anticipation.

## Assets

- `smartevent-mark.svg`: original vector mark, square viewBox 32 × 32, usable at small sizes.
- `../../src/app/icon.svg`: the same mark installed through Next.js automatic favicon metadata.
- `smartevent-banner-v1.png`: original wide banner art, generated with the built-in imagegen tool. Used on login and registration with responsive cropping and live HTML copy.
- `../../src/components/brand/smartevent-mark.tsx`: accessible decorative vector component used next to the visible SmartEvent wordmark.

The banner intentionally contains no lettering. Keep the SmartEvent name and campaign copy as HTML or editable design text. Preserve the ticket focal point when cropping; use a dark overlay below copy for contrast. Keep the original file unchanged when creating variants.

## Banner generation prompt

Mode: built-in imagegen, new image, opaque background, no reference image.

Use case: ads-marketing / stylized-concept. Asset type: original SmartEvent brand banner background for a professional Vietnamese event ticketing website and the visual panel of its login screen. Create a polished premium editorial 3D still life, wide landscape about 16:9. Established SmartEvent palette: warm terracotta coral #c74b31, apricot #f4aa83, ivory #fff3e9, deep ink navy #182230. Subject: one elegant sculptural coral event admission ticket with subtle rounded corners and semicircular ticket notches, delicate perforation, an embossed simple six-ray spark/star symbol (no words), paired with a sweeping satin ribbon and a few smooth circular stage-light forms. Suggest anticipation and live experiences, not financial cards or a generic tech dashboard. Minimal contemporary product photography / high quality restrained 3D art direction, convincing tactile matte paper and soft satin, sculptural shadows, gently lit atmospheric deep ink background with subtle warm amber stage spotlights. Strong ticket focal point in the upper center-right; sweeping ribbon leads downward, lower left stays clean dark negative space for legible HTML text added later. Compose so central ticket remains recognizable when cropped to a tall login side panel. Sophisticated, clean, uncluttered, broad tonal gradients, no busy crowd or people, no neon cyberpunk, no floating UI, no glass cards, no fake QR codes, no readable text, no watermarks, no existing entertainment or artist trademarks. This is one finished usable image, not a moodboard or a grid.
